HEGoGeoSurfaces
===============

**Inherits:** ``RefCounted``

A cooked node's surfaces, read and split from code.

.. rst-class:: classref-introduction-group

Description
-----------

Returned by :ref:`HEGoAssetNode.get_surface_output()<class_HEGoAssetNode_method_get_surface_output>`, and the surface counterpart of :ref:`HEGoGeoOutput<class_HEGoGeoOutput>`: where that one selects points, this selects primitives and turns a group of them into a Godot surface array.

::

    var output = await _await_task(asset_node.get_surface_output(["N", "uv"], ["hego_mesh_instance", "hego_material"]))

    var by_instance = output.split_by("hego_mesh_instance")
    for instance_name in by_instance:
        var by_material = by_instance[instance_name].split_by("hego_material")
        for material in by_material:
            var surface = by_material[material].get_surface(["hego_lod"])
            arr_mesh.add_surface_from_arrays(Mesh.PRIMITIVE_TRIANGLES, surface["surface_array"])



The primitive and vertex lists and the point attributes are read once for the whole mesh part. Splitting is index work; a group only compacts the points its own primitives use, and only when :ref:`HEGoGeoPrimSelection.get_surface()<class_HEGoGeoPrimSelection_method_get_surface>` is called, so a mesh split into many materials does not pay for the whole mesh per material.



Attribute values come from the same per-cook cache as every other output, so the point attributes this reads cost nothing if another output already read them.



Note that the geometry attributes HEGo reads - ``N``, ``Cd``, ``uv``, ``uv2`` and the tangents - are **point** attributes. Promote vertex attributes to points in your HDA before outputting.
