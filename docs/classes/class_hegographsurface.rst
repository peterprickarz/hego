HEGoGraphSurface
================

**Inherits:** ``RefCounted``

Finds the ground under a :ref:`HEGoGraph3D<class_HEGoGraph3D>` point, for snapping and for draping the

 path visualisation.

.. rst-class:: classref-introduction-group

Description
-----------

The surface is, in order:

 

1. the graph's :ref:`HEGoGraph3D.surface_provider<class_HEGoGraph3D_property_surface_provider>` node, when it has a

 ``sample_height(Vector2) -> float`` method (height in the provider's local

 space at a local x/z position). A ``contains_position(Vector2) -> bool``\ 

 method, when present, limits where it answers. Nothing here depends on a particular

 terrain addon.

 

2. a physics ray straight down, when the graph's world has colliders.

 

 A query that finds nothing returns an empty dictionary and callers keep the point's

 height.
