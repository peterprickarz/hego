HEGoTextureInputNode
====================

**Inherits:** :ref:`HEGoBaseNode<class_HEGoBaseNode>` **<** :ref:`HEGoTrackableNode<class_HEGoTrackableNode>` **<** ``RefCounted``

Uploads a Godot ``Image`` or ``Texture2D`` as a Houdini Copernicus layer.

.. rst-class:: classref-introduction-group

Description
-----------

Call :ref:`set_image()<class_HEGoTextureInputNode_method_set_image>` or :ref:`set_texture()<class_HEGoTextureInputNode_method_set_texture>` in an active session to create the input and upload its pixels. Keep this object while the HDA uses it. Updating the same object preserves its Houdini output connection.



Connect the texture with :ref:`HEGoTransformableInputReceiverNode.connect_input()<class_HEGoTransformableInputReceiverNode_method_connect_input>`. A SOP input receives one point at the origin with a string attribute named ``hego_cop_path``. Read that attribute in the COP Path of a Fetch COP inside the HDA. A compatible COP HDA input receives the image layer directly. Use :ref:`HEGoMergeNode.connect_inputs()<class_HEGoMergeNode_method_connect_inputs>` to send several texture points to a SOP socket. HDAs with an explicit COP node-reference parameter can also use :ref:`HEGoAssetNode.set_node_parm()<class_HEGoAssetNode_method_set_node_parm>`.



The upload uses the base mip level and preserves one to four channels. Choose the encoding of the actual pixel values. A luminance-alpha image is transferred as two components in luminance, alpha order.

Method Descriptions

.. _class_HEGoTextureInputNode_method_set_image:

.. rst-class:: classref-method

:ref:`HEGoTask<class_HEGoTask>` **set_image**\ (\ image\: ``Image``, encoding\: :ref:`ImageEncoding<enum_HEGoTextureInputNode_ImageEncoding>` = 0, force\: ``bool`` = false\ ) :ref:`🔗<class_HEGoTextureInputNode_method_set_image>`

Captures ``image`` when called and uploads its finite samples as linear floats. The task returns the Houdini output node ID. Repeating the same image and encoding reuses the existing upload. Pass ``force`` to upload again. An empty image, an unsupported image format, or a compressed format Godot cannot decode fails the task.
