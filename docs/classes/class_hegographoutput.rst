HEGoGraphOutput
===============

**Inherits:** ``RefCounted``

Turns output points flagged as graph points into :ref:`HEGoGraph3D<class_HEGoGraph3D>` nodes under

 ``Outputs/``.

.. rst-class:: classref-introduction-group

Description
-----------

Houdini polylines reach Godot through the loose-point output: the HDA keeps its curve

 points (Add SOP, "Delete Geometry But Keep the Points") and links each point to the one

 before it on its curve.

 



 **Point attributes the HDA sets**\ 

 

- ``hego_graph`` (int): 1 on every graph point. Other points are left to the

 other handlers.

 

- ``hego_graph_path`` (string, optional): node path under

 ``Outputs`` of the graph the point belongs to, default ``Graph``. One

 cook can build several graphs.

 

- ``hego_graph_id`` (int, optional): an id unique within the cook, default

 the point number.

 

- ``hego_graph_prev`` (int, optional): the id of the point this one connects

 to, -1 for none. A polyline links every point but the first to its predecessor; a

 shared id (a fork point) joins curves into one graph.

 

- ``hego_graph_conn_<name>``: becomes the connection attribute

 ``<name>`` of the connection from this point to its predecessor.

 

- Every other point attribute except ``P`` and the ``hego_``\ 

 prefix becomes a point attribute of the graph, declared on an ``Attributes``\ 

 child: floats, ints, strings and three-float vectors.

 



 A graph built this way edits, saves and feeds another cook like an authored one.
