HEGoTerrain3DInput
==================

**Inherits:** ``RefCounted``

Reads an existing Terrain3D node into heightfield layers Houdini can consume.

.. rst-class:: classref-introduction-group

Description
-----------

Terrain3D stores terrain as independent square regions; Houdini wants one rectangular heightfield. The regions are stitched into a single image, and the control map is unpacked into one weight layer per texture used, plus masks marking which pixels belong to a region at all and which are holes.
