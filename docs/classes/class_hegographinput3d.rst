HEGoGraphInput3D
================

**Inherits:** ``Node3D``

A 3D graph of points and connections that can be fed into a :ref:`HEGoNode3D<class_HEGoNode3D>` input.

.. rst-class:: classref-introduction-group

Description
-----------

Add a :ref:`HEGoGraphAttributes<class_HEGoGraphAttributes>` child to declare the attributes each point and connection can carry. Positions are stored in local space. Connections are undirected unique pairs; a point with three or more connections is an intersection.
