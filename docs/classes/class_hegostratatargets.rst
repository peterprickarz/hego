HEGoStrataTargets
=================

**Inherits:** :ref:`HEGoCookExtension<class_HEGoCookExtension>` **<** ``Node``

Publishes the heightfields an HEGo node's HDA outputs into procedural terrain layers.

.. rst-class:: classref-introduction-group

Description
-----------

Add it as a child of an :ref:`HEGoNode3D<class_HEGoNode3D>` and list the layers in :ref:`targets<class_HEGoStrataTargets_property_targets>`. A cook then becomes one transaction: every terrain input is snapshotted before upload, every target receives a complete validated result, and anything that changes or fails along the way leaves all previous results, terrain and Outputs alike, in place. Paths in :ref:`targets<class_HEGoStrataTargets_property_targets>` are relative to the HEGo node, the same as its input paths.
