HEGoGeoSelection
================

**Inherits:** ``RefCounted``

A set of points of a :ref:`HEGoGeoOutput<class_HEGoGeoOutput>`.

.. rst-class:: classref-introduction-group

Description
-----------

A selection is a list of point indices, not a copy of the geometry. Filtering and splitting build new selections without touching attribute values, so narrowing a hundred thousand points down to the few hundred you want costs almost nothing; only :ref:`get_points()<class_HEGoGeoSelection_method_get_points>` assembles data, and only for the points the selection holds.



Selections chain, which is how one HDA output feeds several handlers:

::

    var scattered = output.filter_by("hego_spawn", 1)
    var by_path = scattered.split_by("hego_node_path")
    for node_path in by_path:
        var points = by_path[node_path].get_points(["N", "up", "pscale"])



Obtained from :ref:`HEGoGeoOutput.select_all()<class_HEGoGeoOutput_method_select_all>`, :ref:`HEGoGeoOutput.filter_by()<class_HEGoGeoOutput_method_filter_by>` or :ref:`HEGoGeoOutput.split_by()<class_HEGoGeoOutput_method_split_by>`.
