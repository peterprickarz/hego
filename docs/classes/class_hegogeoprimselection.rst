HEGoGeoPrimSelection
====================

**Inherits:** ``RefCounted``

A set of primitives of a :ref:`HEGoGeoSurfaces<class_HEGoGeoSurfaces>`.

.. rst-class:: classref-introduction-group

Description
-----------

A selection is a list of primitive indices, not a copy of the geometry. Filtering and splitting build new selections without touching any geometry; only :ref:`get_surface()<class_HEGoGeoPrimSelection_method_get_surface>` assembles anything, and only for the primitives the selection holds.



Selections chain, which is how one mesh output becomes one node per instance name with one surface per material:

::

    var by_material = surfaces.filter_by("hego_visible", 1).split_by("hego_material")
    for material in by_material:
        var surface = by_material[material].get_surface(["hego_lod", "hego_col_type"])



Obtained from :ref:`HEGoGeoSurfaces.select_all()<class_HEGoGeoSurfaces_method_select_all>`, :ref:`HEGoGeoSurfaces.filter_by()<class_HEGoGeoSurfaces_method_filter_by>` or :ref:`HEGoGeoSurfaces.split_by()<class_HEGoGeoSurfaces_method_split_by>`.

.. _class_HEGoGeoPrimSelection_method_get_surface:

.. rst-class:: classref-method

``Dictionary`` **get_surface**\ (\ read_attribs\: ``PackedStringArray`` = PackedStringArray()\ ) :ref:`🔗<class_HEGoGeoPrimSelection_method_get_surface>`

Builds the Godot surface for these primitives, as ``{ "surface_array": [...], <requested attributes>: [...] }``.



\ ``surface_array`` goes straight into ``ArrayMesh.add_surface_from_arrays()``. It holds only the points these primitives use, compacted, with the indices remapped to match.



The requested primitive attributes come back as one value per primitive in this selection, in the same order as :ref:`get_indices()<class_HEGoGeoPrimSelection_method_get_indices>`. Attributes the HDA does not have are left out, so read them with ``Dictionary.get()`` rather than assuming the key exists.
