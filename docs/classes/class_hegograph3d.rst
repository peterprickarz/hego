HEGoGraph3D
===========

**Inherits:** ``Node3D``

**Inherited By:** :ref:`HEGoGraphInput3D<class_HEGoGraphInput3D>`

A 3D graph of points and connections: authored as a :ref:`HEGoNode3D<class_HEGoNode3D>` input, or built by a

 cook's graph output (see :ref:`HEGoGraphOutput<class_HEGoGraphOutput>`).

.. rst-class:: classref-introduction-group

Description
-----------

Add a :ref:`HEGoGraphAttributes<class_HEGoGraphAttributes>` child to declare the attributes each point and connection

 can carry; a graph built by a cook gets one listing what the HDA sent. Positions are

 stored in local space. Connections are undirected unique pairs; a point with three or

 more connections is an intersection. Any graph can feed another cook's input.

 

 Large graphs (tens of thousands of points) draw only their connection lines while they

 are not being edited; point markers appear when the graph is selected, up to

 :ref:`marker_limit<class_HEGoGraph3D_property_marker_limit>`.
