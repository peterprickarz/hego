# Copia addon package

This standalone package is built from source commit eb37cce1921337eb7ebda560242b14eb9bc68992. It depends on Godot
and godot-cpp, but does not require HEGo or Houdini. It ships Linux x86_64 and
Windows x86_64 libraries; macOS is not supported. See `PACKAGE.json` for the
package dependency declaration and `native-build.json` for binary receipts.
