# HEGo addon package

This package is built from source commit e06b1ebe8840e8af966661a5327608f934a0b85d. It has no package dependencies.
To cook HDAs into Strata layers, also install the Strata package and
the HEGo Strata package from the same source revision; for Terrain3D, install
the HEGo Terrain3D package from the same revision and Terrain3D itself; to write
HDA points into Copia instancing stores, install the Copia package and the HEGo
Copia package from the same revision. Native
binaries are accepted only when their build receipts match this source revision.
